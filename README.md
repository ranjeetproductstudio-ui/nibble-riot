# Nibble Riot privacy policy

Public privacy-policy page for the offline Android game.

Policy URL: https://ranjeetproductstudio-ui.github.io/nibble-riot/

Privacy contact: ranjeetproductstudio@gmail.com

This repository contains only the policy page and hosting metadata. Game source, builds, art, signing keys and credentials belong outside this public repository.

GitHub Pages publishing source: `main` branch, `/ (root)` folder. No dependencies or build step are needed.

The policy currently describes Android versions 0.1.0 and 0.1.1. Recheck the policy and Play disclosures whenever data practices change.
